# Paper Folder Structure

## 📁 Organization

```
paper/
├── 📋 PAPER_TRACKER.md              # Progress tracking
├── 📄 paper_guidelines.md            # College guidelines
├── 📄 ieee_format_and_guidelines.md  # IEEE formatting rules
├── 📄 ieee_paper_guidelines.md       # General writing guidelines
│
├── 📂 input/                         # Reference materials
│   └── presentation_final.md         # Reviewed presentation
│
├── 📂 source-materials/              # Raw content extracted from presentation
│   ├── A_DATASET_OVERVIEW.md
│   ├── B_DATASET_PREPROCESSING.md
│   ├── C_METHODOLOGY_OVERVIEW.md
│   ├── D_MODEL_ARCHITECTURE.md
│   ├── QUANTITATIVE_RESULTS.md
│   └── GRAPHICAL_RESULTS.md
│
├── 📂 drafts/                        # Paper section drafts (Work in progress)
│   ├── ABSTRACT.md
│   ├── I_INTRODUCTION.md
│   ├── II_LITERATURE_REVIEW.md
│   ├── III_METHODOLOGY.md
│   ├── IV_RESULTS.md
│   ├── V_CONCLUSION.md
│   └── VI_REFERENCES.md
│
├── 📂 final-sections/                # Finalized paper sections (Ready for submission)
│   └── (Empty - will contain polished versions)
│
├── 📂 assets/                        # Visual materials
│   ├── diagrams/                     # System diagrams, flowcharts
│   ├── figures/                      # Screenshots, images
│   └── tables/                       # Data tables
│
└── 📂 references/                    # Bibliography management
    ├── bibliography.bib              # BibTeX file
    └── cited_papers/                 # PDF copies of referenced papers
```

## 📝 Workflow

1. **Source Materials** (`source-materials/`) - Raw content from presentation
2. **Drafts** (`drafts/`) - Working versions of each paper section
3. **Final Sections** (`final-sections/`) - Polished, IEEE-formatted versions
4. **Submission** - Combine final sections into complete paper
