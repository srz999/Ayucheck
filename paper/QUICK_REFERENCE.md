# Quick Reference Guide

## 📍 Where to Find Things

### Need to understand the project?
→ `input/presentation_final.md` - Your reviewed presentation

### Need raw content/data?
→ `source-materials/` - All technical details extracted from presentation

### Working on the paper?
→ `drafts/` - Edit these files to write your paper sections

### Ready to finalize?
→ `final-sections/` - Move polished sections here

### Need formatting help?
→ `ieee_format_and_guidelines.md` & `ieee_paper_guidelines.md`

### Adding images/tables?
→ `assets/` - Store all visual materials here

### Managing references?
→ `references/` - Bibliography and cited papers

## 🔄 Typical Workflow

1. Check `PAPER_TRACKER.md` for current progress
2. Work on files in `drafts/`
3. Reference `source-materials/` for technical content
4. Move completed sections to `final-sections/`
5. Update `PAPER_TRACKER.md` as you progress
